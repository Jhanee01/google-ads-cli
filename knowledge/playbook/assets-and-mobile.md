# Assets and mobile when calls are the goal

When the owner's goal is "more people call me", the traffic was ~76 % mobile and ~87 % of the
impressions showed the phone number. In that situation, in order of impact:

1. **Call-focused ads** next to the responsive search ad: on mobile the whole ad is a call button,
   no website step in between.
2. **Attach the sitelinks and add callouts.** The account had four finished sitelinks that were
   not attached to the campaign, while it lost ~43 % of its impressions to rank. Assets raise ad
   rank at no cost per click.
3. **A positive mobile bid adjustment** (only under manual CPC or Maximize clicks; Smart Bidding
   ignores it).
4. The call asset itself; usually already there.

Check them with the API or the UI before proposing: what exists, what is attached, what is
missing. Creating assets is not in this CLI yet; propose them as a checklist for the UI.
